3. Детали по платформам

Vertex AI: Google объявил native BM25 ranking для AlloyDB и Cloud SQL, подчёркивая, что классический vector search хорошо работает с семантикой, но слаб на точные альфа‑числовые совпадения; BM25 дополняет retrieval-стек (DP). Это конкретное улучшение retrieval-инструментов усиливает их возможности для RAG-сценариев и внутренних data-agent архитектур, то есть повышает качество маршрутизации запросов к данным и relevance-aware routing (CP). Для SL2 AI Platform это усиливает конкурентное давление в слое LLM routing / retrieval: крупный провайдер делает RAG-паттерны более надёжными для своих клиентов, что затрагивает наш тезис о преимуществах LLM-routing (SP → затрагивает G6 как дополнительное давление на наш LLM gateway/обвязку). Следим за тем, пойдёт ли Google дальше по интеграции retrieval в agent-runtime (например, демонстрации RAG-систем с управлением агентов). Сигналы: Announcing Native BM25 Ranking in AlloyDB and Cloud SQL

AWS Bedrock: на неделе AWS опубликовал ряд релизов и гайдов: новый AgentCore runtime (фокус на скорость старта и управление памятью), публикации по миграции multi-model агентных систем на Bedrock AgentCore и анонс Amazon SageMaker HyperPod Inference Gateway — Kubernetes‑native routing для GPU-aware placement (DP). В топологии это усиливает их позицию по Indep. scale (позволяет более эффективно масштабировать inference и снизить latency) и по Prod-ops (инструменты для мониторинга/alarms/managed endpoints) (CP). Для SL2 AI Platform это прямое конкурентное давление: managed-провайдер сокращает инфраструктурную стоимость владения агентами у клиентов и даёт им быстрый путь к elastic/cheap inference, что вскрывает наш GAP в Prod-ops и FinOps (G3/G4). Однако Bedrock остаётся managed/SaaS и не заменяет self-host для строгих требований по резидентности — это сохраняет наше конкурентное преимущество по Self-host. Нужен мониторинг их дальнейшей работы в части per-agent billing и per-agent observability. Сигналы: The new AgentCore runtime: Elastic, optimized, and consistently fast starts, Migrating multi-model AI agents to Amazon Bedrock AgentCore runtime, Introducing Amazon SageMaker HyperPod Inference Gateway

Azure Foundry: Microsoft выпустил Foundry Dev Pack — единый инсталлятор для подготовка машины разработчика к работе с Foundry (DP). Это улучшает onboarding и снижает трение при старте разработки, то есть позитивно влияет на developer experience и частично на Git-native / dev flow (CP). Для SL2 AI Platform это не меняет наш self-host/gap‑профиль, но усиливает давление по части developer enablement: если крупные облака делают «one command» setup, это увеличивает ожидания клиентов по простоте старта (SP → затрагивает G1 — отсутствие visual builder и порог входа). Сигнал: Introducing Foundry Dev Pack: One Command to Start Building

AutoGen: в сообществе Microsoft AutoGen активные обсуждения — от предотвращения «silent loops/stampedes» у агентов до публикации open A2A‑совместимой версии Compliance Gate (DP). Есть предложения по Latent Space протоколу для межагентной коммуникации и дискуссии по интеграциям с Bedrock (CP). Для SL2 AI Platform это сигнал ускоряющейся конвергенции вокруг A2A‑практик и операционных примитивов для multi-agent systems, что прямо затрагивает наш GAP G2 (Agent Protocol не совместим с A2A) и G3 (prod-ops вопросы: loop prevention, agent auth). Нужно отслеживать стандартизацию A2A и доступность референс-primitive, чтобы планировать адаптер A2A в будущем. Сигналы: AlgoVoi open Decision chain (Apache-2.0), How are you guys stopping agents from silent loops/stampedes?

AgentForce (Salesforce): серия публикаций по Hosted MCP Server, security best practices и появление «Abilities» в Vibes (intent-driven tool selection) — DP. Это усиливает их возможности по intent‑driven routing и enterprise integrations, а также по безопасности hosted runtimes (CP). Для SL2 AI Platform это прямое конкурентное давление в сегменте enterprise-agent orchestration и LLM routing (Abilities похожи на наши intent-routing), особенно у клиентов CRM/enterprise — затрагивает G6 (LLM gateway / routing) и G5 (если клиенты требуют self-hosted observability/guardrails). В то же время Salesforce — клауд/hosted-first, и у нас сохраняется преимущество self-host. Сигналы: 開発の意図に応じてツールを自動で選択 – Agentforce Vibesの新機能「アビリティ」, Hosted MCP Serverを使ってSalesforceにSlackを接続する

LangGraph (langchain): релизы пакетов, включая первые alpha релизы langchain-typesafe и основную ветку langchain 1.4.x (DP). Это повышает удобство разработки и типовую безопасность для разработчиков multi-agent/workflow (CP). Для SL2 AI Platform это усиливает давление со стороны open-source SDK-экосистемы: проще писать интеграции и шаблоны агентов, что повышает ожидания по developer experience (SP → затрагивает G7 по зрелости нашего community/docset — нам нужно активнее работать с примерами и библиотеками). Сигналы: langchain==1.4.2, langchain-typesafe==0.0.1a3

n8n: выпустили несколько материалов по практикам снижения AI-workflow latency (model routing, caching, parallel execution), статья про Gateway credits (возможность использовать модели/инструменты в облаке без провайдера) и регулярные релизы (DP). Это улучшает их позицию как оркестратора workflow с фичами model routing и упрощённым доступом к моделям (CP). Для SL2 AI Platform это конкурентное давление в двух областях: LLM routing / gateway (они упрощают запуск RAG/AI‑workflow для не‑infra команд) и Prod-ops (latency-patterns, rate limiting) — затрагивает наши G6 и G3/G4. Особенно важно отслеживать, насколько Gateway credits будут приняты командами с требованиями по приватности. Сигналы: Reducing AI Workflow Latency: Patterns That Actually Work, Try new models and services, skip the account setup

NetBox: релиз v4.7.1 и серия обсуждений багов/feature-requests (DP). Это обычный цикл поддержки/стабилизации OSS-инструмента; прямого влияния на критерии SL2 AI Platform нет (CP). Для SL2 AI Platform — нет изменений в позиционировании, но релизы сообщества указывают на активность и внимание к stability практикам у OSS-проектов. Сигнал: v4.7.1 - 2026-09-15

GLPI: несколько security-релизов (11.0.9, 10.0.27, RC 12.0.0-rc2) — DP. Это призыв к апгрейду для пользователей; влияние на SL2 AI Platform отсутствует (CP). Сигнал: 11.0.9

iTop: релиз 3.3.0 (DP). Технический релиз ITSM-инструмента, без видимого влияния на нашу топологию (CP). Сигнал: 3.3.0

Snipe-IT: обсуждения проблем при апгрейде и баги видимости локаций (DP). Это операционные/поддерживающие обсуждения, прямого влияния на SL2 AI Platform нет (CP). Сигналы: Issue upgrading to v8.4.1 (Permission Issue?), [[Bug]: Locations without company assignment no longer visible since v8.6.3](https://github.com/grokability/snipe-it/discussions/19672)

8. Self-check

  • Непроверенные источники этой недели:
  • AutoGen — множество дискуссий на GitHub (идеа/пулы); высокая активность, но формальный стандарт A2A ещё не утверждён (источники: github discussions). Уверенность — средняя.
  • n8n Gateway credits — анонс фичи в блоге (высокая уверенность в релизе), но неизвестны метрики принятия и enterprise‑ограничения (что важно для оценки реальной угрозы).
  • Bedrock — публичные релизы ясны, но детали per-agent billing/observability adoption — не опубликованы.
  • Слабые допущения:
  • Предположение, что Bedrock AgentCore быстро переведёт значимые enterprise‑флаги клиентов от self-host к managed; возможно, крупные регулируемые клиенты останутся на self-host. Это допущение может оказаться чрезмерно пессимистичным.
  • Оценки влияния AutoGen на стандарт A2A сделаны на основании community‑релизов; реальная отраслeвая консолидация может занять больше времени.
  • Что отслеживать на следующей неделе (t):
1. Появление у AWS Bedrock публичных кейсов «per-agent billing» или per-agent observability/trace примеров (проверка BDR-001/BDR-002) — мониторить AWS блоги и customer stories.

2. Adoption/metrics по n8n Gateway credits: появление кейсов enterprise/соглашений о приватности (NDA), и/или релиз подробной документации по security/residency.

3. Дальнейшие шаги AutoGen в направлении A2A: новые репозитории/спецификации, принятие другими OSS-проектами (langchain и др.).

На этом отчёт заканчивается.
