3. Детали по платформам

Vertex AI: Google расширил Antigravity для enterprise-клиентов, добавив governance-контроли и улучшенную делегацию задач между агентами (DP). Это усиливает критерий Prod-ops за счёт встроенных механизмов аудита и контроля доступа, а также улучшает Multi-tenancy через централизованное управление агентами (CP). Для SL2 AI Platform это давление на GAP G3 (observability) и G4 (FinOps), так как Vertex AI теперь предлагает managed-решения с встроенным трейсингом и cost tracking, которые у нас требуют дополнительной интеграции (SP). Однако Antigravity остаётся closed SaaS, что сохраняет наше преимущество для self-host клиентов.

Сигналы: Expanding Google Antigravity, How agents can delegate better

AWS Bedrock: AWS выпустил в GA AgentCore Gateway для governed tool access и добавил cross-Region inference для OpenAI GPT-5.6 моделей (DP). Это закрывает критерии Indep. scale (изоляция агентов в microVM) и Secrets/tenant (governed tool access), а также улучшает Prod-ops через аудит вызовов инструментов (CP). Для SL2 AI Platform это прямое давление на GAP G3 (observability) и G4 (FinOps), так как Bedrock теперь предлагает managed-решения с встроенным cost tracking и аудитом, которые у нас требуют ручной настройки (SP). Однако Bedrock остаётся closed SaaS с vendor lock-in, что сохраняет наше преимущество для self-host клиентов.

Сигналы: Govern AI agent tool access with Amazon Bedrock AgentCore Gateway, Cross-Region inference for OpenAI GPT-5.6

Azure Foundry: Microsoft интегрировал пять новых возможностей Claude, включая structured outputs, web search и MCP connector (DP). Это усиливает критерий Unified API + контракт за счёт MCP connector, который позволяет агентам взаимодействовать через стандартный протокол (CP). Для SL2 AI Platform это давление на GAP G2 (Agent Protocol lock-in), так как MCP может стать новым стандартом для межагентного взаимодействия, а мы пока не поддерживаем его (SP). Однако Foundry остаётся closed платформой, что ограничивает её привлекательность для self-host клиентов.

Сигналы: Five new Claude capabilities in Microsoft Foundry

AutoGen: Сообщество выпустило Agent Memory Guard — middleware для защиты памяти агентов от инъекций и утечек данных, а также AgentGraph — инфраструктуру для trust verification (DP). Это усиливает критерий Prod-ops за счёт улучшенной безопасности и observability межагентных взаимодействий (CP). Для SL2 AI Platform это давление на GAP G3 (observability), так как AutoGen теперь предлагает решения для защиты памяти и верификации агентов, которые у нас требуют дополнительной разработки (SP). Однако AutoGen находится в maintenance mode, что ограничивает его конкурентоспособность.

Сигналы: Agent Memory Guard, AgentGraph

AgentForce: Salesforce запустил Data 360 Headless для расширения возможностей агентов за пределы Salesforce (DP). Это усиливает критерии Multi-tenancy и Unified API + контракт за счёт предоставления headless-доступа к данным и инструментам через стандартные API (CP). Для SL2 AI Platform это давление на GAP G2 (Agent Protocol lock-in) и G7 (зрелость), так как AgentForce теперь предлагает более зрелую экосистему интеграций и протоколов (SP). Однако платформа остаётся закрытой и vendor-locked.

Сигналы: Data 360 Headless

LangGraph: Выпущены обновления SDK 0.4.3 и интеграции с новыми LLM-провайдерами (Perplexity, Fireworks) (DP). Это улучшает критерий LLM routing за счёт расширения списка поддерживаемых моделей, но не меняет топологию платформы кардинально (CP). Для SL2 AI Platform это не создаёт прямого давления, так как LangGraph фокусируется на orchestration, а не на runtime-платформе (SP). Однако расширение экосистемы может усилить конкуренцию в будущем.

Сигналы: langgraph-sdk==0.4.3, langchain-perplexity==1.4.1

n8n: Добавлена интеграция с Amazon Bedrock AgentCore для создания multi-agent команд с общей памятью (DP). Это улучшает критерий Prod-ops за счёт встроенной observability и управления памятью (CP). Для SL2 AI Platform это давление на GAP G3 (observability), так как n8n теперь предлагает managed-решение с лучшей поддержкой межагентных взаимодействий (SP). Однако n8n остаётся low-code платформой, что ограничивает её привлекательность для enterprise-разработчиков.

Сигналы: Build multi-agent teams with Amazon Bedrock AgentCore

NetBox: Выпущен релиз v4.7.0-beta1 с улучшениями UI и обсуждениями по backup restore (DP). Это не затрагивает напрямую критерии SL2 AI Platform, так как NetBox — это IT-инфраструктурный инструмент, а не AI-платформа (CP). Для нас это не создаёт давления (SP).

Сигналы: v4.7.0-beta1

Ralph: Прекращена поддержка deb-пакетов, фокус смещён на Docker-дистрибуцию (DP). Это не затрагивает критерии SL2 AI Platform напрямую, так как Ralph — это asset management система (CP). Для нас это не создаёт давления (SP).

Сигналы: 20260819.1

Snipe-IT: Выпущены патч-релизы v8.7.1 и v8.7.2 с фиксами импортера и SCIM (DP). Это не затрагивает критерии SL2 AI Platform напрямую, так как Snipe-IT — это IT-инвентаризационная система (CP). Для нас это не создаёт давления (SP).

Сигналы: v8.7.2
