3. Детали по платформам

Vertex AI: Google расширил Gemini Enterprise Agent Platform, добавив интеграцию с GKE для снижения стоимости агентов на 75% (DP). Это усиливает критерии Indep. scale (HPA на уровне GKE) и Prod-ops (наблюдаемость через Cloud Logging). Для SL2 AI Platform это давление на GAP G4 (cost tracking) и G3 (observability), так как Vertex AI теперь предлагает managed-решение с прозрачным ценообразованием и интегрированными инструментами мониторинга. Однако self-host остаётся нашим преимуществом для клиентов с жёсткими требованиями к data residency.

Сигналы: GKE cost reduction, Gemini Enterprise updates

AWS Bedrock: AWS выпустил в GA AgentCore Runtime с изоляцией агентов в microVM и Observability для диагностики производительности (DP). Это закрывает критерии Indep. deploy/scale и Secrets/tenant (KMS для аутентификации), усиливая enterprise-позиционирование Bedrock. Для SL2 AI Platform это прямая угроза по G3 (inter-agent tracing) и G4 (cost tracking), так как AWS теперь предлагает managed-альтернативу с лучшей наблюдаемостью. Однако Bedrock остаётся SaaS, что сохраняет наше преимущество для self-host клиентов.

Сигналы: AgentCore Observability, microVM isolation

AutoGen: Microsoft объявил о переводе AutoGen в maintenance mode и рекомендовал миграцию на Microsoft Agent Framework (DP). Это ослабляет критерий Unified API + контракт, так как AutoGen больше не будет развивать собственные стандарты (CP). Для SL2 AI Platform это сигнал о риске G2 (Agent Protocol lock-in), так как индустрия движется к стандартизации (A2A). Однако AutoGen остаётся open-source, что сохраняет его актуальность для self-host сценариев.

Сигналы: Maintenance mode announcement, A2A discussion

AgentForce: Salesforce представил Metadata API Context Skills для AI-агентов, улучшая интеграцию с Salesforce-метаданными (DP). Это усиливает критерий Multi-tenancy (group-based ACL) и Secrets/tenant (контроль доступа на уровне групп). Для SL2 AI Platform это давление на G1 (visual builder), так как AgentForce предлагает более низкий порог входа для не-разработчиков. Однако их решение остаётся SaaS-only, что сохраняет наше преимущество для self-host клиентов.

Сигналы: Metadata API Skills, Enterprise security

LangGraph: Выпущены релизы checkpoint-систем для PostgreSQL/SQLite (3.1.1) и улучшения ядра (1.2.10) (DP). Это усиливает критерий Prod-ops (надёжность хранения состояний), но не затрагивает другие критерии. Для SL2 AI Platform это косвенное давление на G3 (observability), так как LangGraph улучшает отказоустойчивость своих агентов. Однако их фокус на Python-first подходе сохраняет наш GAP по Code+No-code (G1).

Сигналы: PostgreSQL checkpoint release, Core updates

n8n: Опубликованы статьи по LLM Security и AI Agent Identity Management для production-развёртываний (DP). Это усиливает критерий Prod-ops (безопасность и аудит) и Code+No-code (visual builder для workflows). Для SL2 AI Platform это давление на G1 (visual builder) и G3 (observability), так как n8n предлагает более зрелые инструменты для enterprise-безопасности. Однако их фокус на workflow-автоматизации отличается от нашего agent-first подхода.

Сигналы: LLM Security, AI Agent Identity

NetBox: Релиз v4.6.7 с улучшениями производительности и анонс DORA-комплаенса для инфраструктурных команд (DP). Это усиливает критерий Prod-ops (наблюдаемость инфраструктуры), но не затрагивает AI-агентов напрямую. Для SL2 AI Platform это косвенный сигнал о важности G5 (self-hosted observability), так как NetBox фокусируется на data residency для инфраструктурных данных.

Сигналы: v4.6.7 release, DORA compliance blog

Ralph: Релиз экспериментальной фичи switchports (DP). Это не затрагивает AI-критерии, но сигнализирует о развитии инфраструктурного управления. Для SL2 AI Platform релевантности нет.

Сигналы: 20260729.1 release

Snipe-IT: Обсуждения UI/UX-модернизации и интеграции с Jira Cloud (DP). Это не затрагивает AI-критерии напрямую, но сигнализирует о фокусе на enterprise-интеграциях. Для SL2 AI Platform релевантности нет.

Сигналы: UI/UX discussion, Jira Cloud integration
